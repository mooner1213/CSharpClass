# Unity C# 기초 학습

Unity 환경에서 C# 문법과 객체 지향 프로그래밍을 실습한 학습 프로젝트입니다.

## 학습 범위

- 변수와 자료형 및 형 변환
- 연산자와 조건문·반복문
- 배열과 함수 및 메서드 오버로딩
- 구조체와 열거형 및 클래스
- 예외 처리와 컬렉션·제네릭·LINQ
- 네임스페이스와 접근 제한자

## 구성과 확인 방법

| 경로 | 역할 |
| --- | --- |
| [Assets/Scripts](Assets/Scripts) | 번호와 주제별 예제 |
| [Assets/Scenes/SampleScene.unity](Assets/Scenes/SampleScene.unity) | 기본 실습 씬 |
| [Packages](Packages) | 패키지 의존성 |
| [ProjectSettings](ProjectSettings) | Unity 프로젝트 설정 |

Unity Hub에서 프로젝트를 추가하고 **Unity 6000.3.13f1**로 엽니다. 확인할 MonoBehaviour 예제를 씬 오브젝트에 연결하고 Console에서 결과를 확인합니다. 예제마다 호출 방식이 다르며 모든 파일을 한 번에 실행하는 게임 프로젝트는 아닙니다.

강의 예제와 문법 연습을 포함하는 학습 아카이브입니다.
